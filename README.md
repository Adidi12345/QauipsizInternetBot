# Қауіпсіз интернет көмекшісі — Telegram Bot

Java 17 + Maven. Telegram Bot API используется напрямую через Java HttpClient; для JSON используется Jackson.

## Запуск в IntelliJ IDEA

1. Создай бота через [@BotFather](https://t.me/BotFather) командой `/newbot` и сохрани токен.
2. Открой эту папку через **File → Open** в IntelliJ IDEA.
3. Дождись импорта Maven зависимостей. Убедись, что Project SDK = **JDK 17**.
4. Открой `src/main/java/kz/qauipsiz/Main.java`.
5. Нажми **Run → Edit Configurations**. Создай конфигурацию **Application** для `kz.qauipsiz.Main`, если она ещё не создана.
6. В **Environment variables** добавь `BOT_TOKEN=твой_токен` (не записывай его в исходники).
7. Запусти `Main` зелёной кнопкой Run.
8. Открой своего бота в Telegram, отправь `/start`.

Если удобнее из терминала macOS:
```bash
export BOT_TOKEN='твой_токен'
mvn compile exec:java
```

## Функции

- 5 основных категорий и 14 подтем из оригинального HTML
- Inline-кнопки для категорий и подтем
- Готовые советы на казахском языке
- Связанные темы и возвращение в меню
- URL-кнопки с полезными ссылками
- Поиск по точному вхождению текста в названиях и содержании подтем
- `/start`, `/menu`, `/help`

Контент расположен в `src/main/resources/topics.json`. Можно редактировать тексты без изменения Java-кода (после изменения нужно перезапустить программу).

Бот работает только пока запущена программа. Для 24/7 потребуется хостинг.

## Безопасность

Токен не хранится в проекте. Не выкладывай его в GitHub. Если токен раскрыт, отзови его через BotFather.
